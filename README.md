# Многостраничный сайт

Базовый многостраничный сайт на HTML, CSS и JavaScript.

## Структура проекта

- `index.html` — главная страница
- `services.html` — страница услуг
- `web.html` — страница «Сайты под ключ»
- `about.html` — страница о компании
- `contact.html` — страница контактов
- `css/style.css` — основные стили
- `css/responsive.css` — адаптивные стили
- `js/main.js` — основной JavaScript
